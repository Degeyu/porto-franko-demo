# Порто Франко — демо сайта

Адаптивный сайт апарт-отеля во Владивостоке. Публикуется на GitHub Pages из ветки main, папка / (root).

Форма подготавливает сообщение для WhatsApp; бронирование подтверждает администратор.

Исходники Astro находятся в архиве porto-franko-source.zip. Для обновления: pnpm install, pnpm build, node scripts/export-github-pages.mjs. Загрузите содержимое каталога porto-franko-github-pages в этот репозиторий.
